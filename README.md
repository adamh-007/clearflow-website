# ClearFlow public website

Public, static marketing website and interactive fictional-data job dashboard.

## Security boundary
- No authentication, database, payment processing, email sending, or live client data.
- Do not put customer information or secrets into this public repository or GitHub Pages.
- The dashboard is explicitly a demonstration, not a client portal.
- Production client access requires a separate authenticated backend, tenant isolation, security review, backup and recovery, and data-processing compliance.

## Local preview
Open index.html in a browser. No build dependencies.

## Hosting
GitHub Pages from main / (root). GitHub Pages hosts static content only.
